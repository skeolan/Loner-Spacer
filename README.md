# Loner: Spacer Campaign

This repository contains the campaign state, chronological play record, setting lorebook, and local rules references for Nova Darkreach and the *Horizon Chaser* in the Quaternary Sector of *The Shattered Reach*.

## Contents

- [Campaign](campaign/README.md) -- current state, chapters, lorebook, and ledgers.
- [Reference](reference/README.md) -- published and searchable local rules references.
  - [Loner SRD](reference/lonersrd/README.md) -- read-only rules submodule.
- [Scripts](scripts/README.md) -- enforced name generation and dice rolling tools.
- [GM Instructions](.instructions.md) -- gameplay and repository operating rules.

## Foam

The optional Foam extension indexes campaign Markdown plus the four authoritative Loner sourcebooks selected in workspace settings. It provides backlinks, graph navigation, and a read-only MCP knowledge-graph server while standard Markdown links and README hubs remain the portable source of navigation.
