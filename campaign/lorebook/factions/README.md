# Factions

## Contents

- [Concordat](concordat.md) -- wealthy Core World alliance.
- [Elder Dominion](elder-dominion.md) -- ancient alien power operating from the shadows.
- [Frontier League](frontier-league.md) -- coalition of outer colonies.
- [Independents](independents.md) -- unaffiliated operators of the Contested Zone.
- [Predecessors](predecessors.md) -- extinct alien civilization whose ruins shape the sector.
