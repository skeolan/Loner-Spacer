# Player

This directory owns mutable player-controlled character and ship state. Put current traits, resources, conditions, and pressures here; record their history in chapters or ledgers instead of duplicating it.

## Contents

- [Nova Darkreach](character-Nova-Darkreach.md) -- current protagonist traits, Luck, gear, wealth, and pressures.
- [Horizon Chaser](ship-Horizon-Chaser.md) -- current ship type, Luck, modules, frailty, condition, and resources.
- [Initialization](init/README.md) -- setup choices, raw generation rolls, and explicit retcons.
