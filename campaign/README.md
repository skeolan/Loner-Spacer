# Campaign

This directory contains everything created or changed through play. Use its child directories to separate current state, chronological fiction, reusable lore, and transaction history.

## Contents

- [Player](./_player/README.md) -- current character and ship truth plus initialization records.
- [Chapters](chapters/README.md) -- chronological fiction and play logs.
- [Lorebook](lorebook/README.md) -- small pages for reusable people, places, factions, threads, and events.
- [Ledgers](ledgers/README.md) -- histories of resource and economic changes.
